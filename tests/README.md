# Tests

End-to-end tests run the generated `index.html` in headless Chromium (Playwright) and simulate drag-and-drop through the Chrome DevTools protocol. Every fixture is generated by `fixtures.js` (synthetic events, a 1×1 PNG, fake projects): nothing in this folder comes from a real conversation.

```
npm install        # once: Playwright (downloads a Chromium build)
npm run build      # regenerate index.html from src/ and engine/
npm test
```
